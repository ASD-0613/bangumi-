# Bangumi 番剧数据查询工具（bangumi_query）v3.3.3

基于 **Bangumi API** 的番剧数据查询工具，以 **Windows 单文件 exe** 形式分发
（PyQt5 图形界面，双击即用，无需安装 Python），**Steam 风格深色界面**。

功能：

1. **搜索番剧** —— 关键词搜索，表格展示，分页浏览；
2. **番剧详情** —— 封面、基本信息、状态、地区、评分、简介、主要声优、
   制作团队与分集列表；
3. **排行榜** —— 类别 × 排序维度双重筛选，50 条数据、每页 10 条可翻页；
4. **追番日历** —— 星期按钮一次只查看一天的更新内容，平铺显示每部番剧；
5. **本地缓存** —— 封面图片磁盘缓存，跨标签页 / 跨启动复用，
   主窗口底部可查看占用并一键清除；
6. **正在看 / 已看完** —— 详情页顶部双段选择器标记状态（“正在看”=黄、
   “已看完”=绿，互斥、可再次点击取消，本机保存）；页签内含两个番剧库
   （Steam 式网格），默认显示「正在看」；
7. **界面主题** —— 全局 Steam 风格主题，评分按档位配色
   （≥9 金色、≥8 绿色）；**主题可选**（默认浅色，深色 / 浅色即时切换
   并记忆）。
   搜索/排行榜/追番日历三处数据栏**行高约 3 倍、字号放大**，并都有独立
   的**封面首列**。

## 安装与运行

**普通用户**：到 [Releases](https://github.com/ASD-0613/bangumi-/releases)
下载 `BangumiQuery-<版本号>.zip`，解压后双击其中的 exe 即可（无控制台窗口、
无需安装 Python）。首次运行如出现 SmartScreen 警告，点「更多信息」→
「仍要运行」（未签名 exe 的正常现象）。

**开发者**（源码仅用于调试与打包，需 Python 3.10+，能访问 `api.bgm.tv`）：

```bash
pip install -r requirements.txt        # PyQt5、requests
python -m bangumi_query.main        # 开发调试运行 GUI
pip install pyinstaller && python build_exe.py   # 打包 exe
```

### GUI 用法要点

- **排版统一**：搜索结果/排行榜/追番日历三处数据栏：每行高度约为默认的
  **3 倍**（84px），数据字号放大至 12pt，并都带独立的**“封面”首列**；
  **封面图的纵向高度与行高一致**（等比缩放保留比例），并在单元格内
  **居中**显示（异步加载、带磁盘缓存，见“本地缓存”）；
- **表格列宽可拖拽**：搜索/排行榜表头可像 Excel 一样拖动分隔线调整宽度；
- **排行榜**：“榜单类别”（全部/日漫/国漫/纪录片/电影）＋“排序维度”
  （热度 / 评分 / 收藏数），**任一下拉改动立即刷新**；请求进行中改动
  筛选不会丢失（结果返回后自动按最新选择补发）；每页 10 条可翻页；
  双击或回车查看详情；
  - **渐进式加载**：进入排行榜首屏只需**一个请求**（约 25 条候选）即可
    显示，后台自动逐页补全至 150 条候选池并重排序渲染；补全期间列表会
    随数据到达自动更新（短暂跳动属预期），“清除缓存”不影响；
- **页签行为**：排行榜 / 追番日历的数据到达时**不再强行切换页签**——
  自动加载期间切去别的页签不会被拽回；加载失败时若已离开该页签，
  仅在状态栏提示，不打断当前操作；
- **追番日历**：“周一 ~ 周日”单选按钮（默认今天）只展示所选当天的更新；
  **选中的星期按钮以绿底白字强调**；“日历类型”下拉改动立即刷新，首次切到
  该标签页时自动加载一次；无数据
  或当日无更新时显示灰色占位行；数据区**没有“周一/周二”可折叠分组行**，
  条目直接平铺；列结构为“**封面 | 番剧名称 | 开播时间**”，名称列约占
  数据栏一半宽（窗口缩放自适应）；“开播时间”= 首话播出日期，逐条异步
  查询并填充（查询中显示 …，失败显示 —）；双击或回车番剧查看详情；
  **番剧名超宽时**，鼠标悬停在该行名称上会**横向滚动显示全名**
  （无框跑马灯：文字底色与所在行一致，只有文字在滚动）；
- **主题切换**：底部“主题：深色 / 浅色”下拉即时切换并记忆
  （**默认浅色**），评分档位配色、占位图等随主题联动；
- **窗口记忆**：窗口大小与位置自动记忆，关闭后下次启动恢复；
- **滚动区域**：剧情简介 / 声优制作框内滚轮只滚框内内容（到边界即停，
  不带动整页）；翻整页请使用空白区域或右侧全局滚动条；
- **详情页**：从搜索结果/榜单/日历均可进入（双击、回车或按钮）；加载中
  改选其他条目立即生效（同一条目加载中重复点击只发一次请求）；分集
  超过 80 条时显示“仅展示前 N 集”截断提示；
  - **状态标记**：标题行最右侧的“正在看 | 已看完”双段选择器——互斥
    可选，再次点击已选中项即取消；选“正在看”底色变黄、选“已看完”
    底色变绿；点击即时保存到本机 `watched.json`（与封面缓存同级，
    不受“清除缓存”影响）；
  - **渐进加载**：条目本体先显示（1 个请求），分集与声优随后台并行
    加载、到达即填充；
- **正在看 / 已看完**：追番日历右侧的页签，顶部双段切换器选择子库
  （默认「正在看」）；Steam 仓库式网格陈列（封面在上、简中名在下），
  单击选中、双击进入详情；封面复用磁盘缓存，最新标记的排最前；
- **分页按钮**：搜索/排行榜的“上一页 / 下一页”按当前页码自动禁用
  （首页禁用上一页、末页禁用下一页）；
- **错误恢复**：请求失败弹窗提示后，按钮与下拉自动恢复可用，可直接重试
  （不会卡在禁用状态）；
- **底部缓存栏**：显示本地缓存的文件数与占用，右下角“清除缓存”点击后
  弹窗三选：**一并清除**（缓存 + 「已看完」记录）/ **仅清缓存**（默认，
  保留记录）/ **取消**；关闭弹窗（X / Esc）等同取消，什么都不清；
- **列宽记忆**：搜索结果 / 排行榜 / 追番日历的列宽拖动会自动记住
  （`settings.json`，与「正在看 / 已看完」记录同级，“清除缓存”不影响）；
  下次打开恢复上次的列宽状态，且拖动后不再被自动铺排覆盖；排行榜
  切换“排序维度”导致列数变化时按记忆重新套用（无记忆则用默认铺排）；
- **全局字体**：应用整体使用微软雅黑；页签名、搜索框、番剧库名称
  等显眼位置为加粗字体。

## 数据来源与接口

接口请求统一携带 `User-Agent: BangumiQuery/<版本号>`
（Bangumi 要求 UA，缺失时返回 403）；封面图片由独立的下载线程获取
（使用浏览器 UA），并写入本地磁盘缓存。

| 功能 | 接口（真实验证） | 说明 |
| --- | --- | --- |
| 搜索番剧 | `POST https://api.bgm.tv/v0/search/subjects` | 关键词 + `filter.type` |
| 番剧详情 | `GET https://api.bgm.tv/v0/subjects/{id}` | 基本信息/评分/简介 |
| 分集列表 | `GET https://api.bgm.tv/v0/episodes?subject_id={id}` | 仅正片（过滤 SP/OP/ED“第0话”等） |
| 角色声优 | `GET https://api.bgm.tv/v0/subjects/{id}/characters` | 动画详情的“主要声优” |
| 排行榜 | `GET https://api.bgm.tv/v0/subjects?type=&sort=rank&limit=&offset=` | 可翻页候选池 → 本地按维度排序取 50 |
| 追番日历 | `GET https://api.bgm.tv/calendar` | 根路径（不带 /v0），`weekday(1..7)` + `items` |

注意：`POST /v0/search/subjects` 的空关键词榜单每请求固定返回前 10 且分页
无效；榜单因此改用 `GET /v0/subjects` 的候选池实现（POST 的 `sort=heat` 仅
用于普通带关键词搜索等场景）。

## 字段映射（按 Bangumi 真实返回）

| Bangumi 字段 | 映射 |
| --- | --- |
| `name_cn`（无则 `name`） | 标题 |
| `summary` | 简介（空 → “暂无简介”） |
| `rating.score` | 评分（0-10，1 位小数） |
| `date` / `air_date` | 播出时间（YYYY-MM-DD） |
| `/v0/episodes` 的 `data[]`（type=0） | 分集列表 |
| `eps`（数字） | 总集数 |
| `collection.*` / `collects` | 收藏数（排行榜“收藏数”维度、详情收藏人数） |
| `tags` / `meta_tags` | 地区（日本/中国/美国/欧美…） |
| characters 的 `actors[]` | 主要声优（角色 → 声优） |
| infobox“放送结束/播放结束/播出结束” | 状态=已完结 |

说明：
- **地区**：Bangumi 详情无 infobox“地区”键，地区取自 `tags`/`meta_tags`
  词表（如“日本/中国/欧美”）并去重；
- **状态**：能确认完结才显示“已完结”；开播日期在约 210 天内且无完结信息
  时保守显示“连载中”；其余显示 “—”；
- **分集**：`/v0/episodes` 会返回“第0话/SP”等非正片条目，程序只保留
  `type=0`（或未标注）的正片，避免多出多余集数。

## 排行榜说明

- 数据流：从 `GET /v0/subjects?type=&sort=rank` 抓取候选池（默认 150 条，
  每页 25、真正 offset 翻页）→ “日漫/国漫”按条目标签地区过滤 → 按
  **排序维度**本地降序 → 取前 50 条；
- 排序维度含义：**热度**=评分人数、**评分**=rating.score、**收藏数**=
  collection 各状态总数；
- `纪录片` / `电影` 使用 type=6（三次元真人影视）候选池，Bangumi 未细分
  纪录片/电影，作为近似数据；
- 若某类别候选池过滤后无匹配，会给出明确提示，不会混入他国条目。

## 网络与代理配置

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `BANGUMI_PROXY` | 未设置 | HTTP(S) 代理，如 `http://127.0.0.1:7890` |
| `BANGUMI_API_BASE` | `https://api.bgm.tv/v0` | 自设网关/镜像（需含 `/v0`） |
| `BANGUMI_CALENDAR_URL` | `https://api.bgm.tv/calendar` | 日历接口地址 |
| `BANGUMI_CONNECT_TIMEOUT` / `BANGUMI_READ_TIMEOUT` | `5` / `10` 秒 | 连接/读取超时 |
| `BANGUMI_RETRY_TIMES` | `2` | 单次请求总尝试次数（含首次；默认 2 即超时/429/5xx 后重试 1 次） |
| `BANGUMI_INSECURE` | `0` | `1` 时关闭 SSL 校验（不推荐） |
| `BANGUMI_CACHE_DIR` | 平台默认 | 封面图片磁盘缓存目录 |

未设置代理时信任系统代理（Windows 注册表代理 / `HTTP_PROXY` /
`HTTPS_PROXY`）；仅 DEBUG 或首次请求打印 `[代理] 使用代理: …`。
网络排障：`python check_network.py`。

## 本地缓存

- 封面图片首次下载成功后写入本地缓存目录（默认 Windows 为
  `%LOCALAPPDATA%\BangumiQuery\cache`，其它平台 `~/.cache/BangumiQuery`，
  可用 `BANGUMI_CACHE_DIR` 覆盖）；缓存按封面图片 URL 区分，同一封面在
  搜索/排行榜/追番日历/详情之间以及下次启动时**直接读缓存，不再重复下载**；
- 主窗口底部显示缓存占用（文件数与大小），右下角“清除缓存”按钮可一键
  清空，成功后弹窗提示；
- 接口 JSON 数据不缓存，保证评分 / 榜单等数据的时效性。

## 打包为 exe（Windows）

生成项目的分发形态——无需安装 Python 的单文件可执行程序（无控制台黑窗）：

```bash
pip install pyinstaller   # 仅构建机需要，运行 exe 的用户不需要
python build_exe.py       # 产物：dist/BangumiQuery-<版本号>.exe
```

- 版本号自动取自 `config.VERSION`；构建参数（onefile + windowed 及依赖排除
  清单）集中在 `build_exe.py`；
- 首次运行如出现 SmartScreen 警告：点「更多信息」→「仍要运行」（未签名
  exe 的正常现象）；
- exe 的封面缓存与脚本版一致（`%LOCALAPPDATA%\BangumiQuery\cache`），
  与 exe 所在位置无关；
- 构建脚本已排除 Anaconda 环境预装的 PySide6 / matplotlib / numpy 等无关
  大件（PyInstaller 不允许两套 Qt 绑定并存）；若你的环境不同导致构建失败，
  按报错信息增删 `build_exe.py` 中的 `EXCLUDES` 即可。

## 已知限制

- “热度”维度以评分人数为代理；评分维度以均分为准（经典高分作品靠前，
  属预期语义）；
- 纪录片/电影仅为 type=6 近似数据；
- Bangumi 不提供播放量等字段，相关列显示 “—”；
- 播出状态无法 100% 可靠（Bangumi 无权威状态字段），程序采用保守推断；
- 追番日历仅覆盖正在放送的动画；“日历类型”（番剧/国创/影视）依赖
  Bangumi 日历数据，暂无法区分日漫/国漫/影视，三个选项当前返回相同内容；
- 追番日历“开播时间（首话日期）”为逐条异步查询（带缓存），首次查看某一天
  会稍慢，失败条目显示 “—”；
- 封面图来自第三方图片服务器，加载失败显示占位；封面下载未使用
  `BANGUMI_PROXY` 指定的代理（系统代理 / `HTTP_PROXY` 等仍然生效）。
